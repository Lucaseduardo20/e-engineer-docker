## ARCHITECTURE QUICK REFERENCE

**Backend (NestJS + DDD):**
- Domain: business logic, entities, value objects
- Application: use cases, DTOs, ports
- Infrastructure: TypeORM, repositories, mappers
- Presentation: controllers, request/response DTOs
- **Key:** Controllers are thin, use cases orquestrate, domain concentrates behavior

**Frontend (Vue 3 + Pinia):**
- Pages: full-page components
- Components: UI components (module-specific or shared)
- Stores: state management (Pinia)
- Services: API client, encapsulate Axios
- Types: API contracts, interfaces
- **Key:** Services call API, Stores consume services, Components consume stores

**Multi-tenancy:**
- Every business entity has `organizationId`
- Repositories receive `organizationId` explicitly
- No implicit global tenant
- Queries always filter by `organizationId`
