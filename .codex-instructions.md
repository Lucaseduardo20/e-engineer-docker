## ARQUITETURA RESUMIDA (Para Referência)

### Backend (NestJS + DDD)
```
src/modules/{name}/
  ├── domain/          (Business logic)
  ├── application/     (Use cases + DTOs)
  ├── infrastructure/  (TypeORM + Repos)
  └── presentation/    (Controllers)
```

**Padrões:**
- Controllers: finos, delegam para use cases
- Use cases: orquestram, chamam domain + repos
- Entities: comportamento + invariantes
- DTOs: entrada/saída, application/presentation
- Multi-tenancy: organizationId obrigatório

### Frontend (Vue 3 + Pinia)
```
src/
├── app/              (Layouts, global styles)
├── modules/          (Feature modules)
│   ├── pages/        (Page components)
│   ├── components/   (Module UI components)
│   ├── stores/       (Pinia stores)
│   ├── services/     (HTTP services)
│   └── types/        (Module types)
├── shared/           (Reusable)
│   ├── http/         (API client)
│   ├── components/   (UI components)
│   ├── types/        (API contracts)
│   └── ui/           (Utils)
└── router/           (Routing + guards)
```

**Padrões:**
- Services: chamam API, encapsulam Axios
- Stores: gerenciam estado, chamam services
- Components: consomem stores, disparam eventos
- Types: API contracts, interfaces explícitas

## 📞 TROUBLESHOOTING

### "Access-Control-Allow-Origin" error
→ Task 1 not done or misconfigured

### Login doesn't work
→ Check DB has seed user: `psql ... "SELECT email FROM users"`
→ Check backend logs for errors

### Projects page shows "No data"
→ Task 5 (ProjectsStore) not updated to use real API
→ Check network tab (F12) for failed requests

### Type errors in npm run type-check
→ Services layer types don't match backend DTOs
→ Update Task 9 (Type Sync)

### E2E test times out
→ Backend may not be running
→ Check `docker-compose logs`
