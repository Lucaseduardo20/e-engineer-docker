# Documentação de Negócio da Plataforma

Este pacote contém as documentações principais para orientar a evolução da plataforma de engenharia.

## Arquivos

1. `business/01-product-vision.md` — visão geral do produto, posicionamento, problema, proposta de valor e fluxo dos sonhos.
2. `business/02-domain-map.md` — mapa de domínio, entidades principais, bounded contexts e relações.
3. `business/03-business-flows.md` — fluxos ideais da plataforma, do onboarding à Base de Conhecimento e viabilidade futura.
4. `business/04-business-rules.md` — regras de negócio para multi-tenancy, projetos, entregáveis, documentos, revisões e conhecimento.
5. `business/05-knowledge-base.md` — documentação aprofundada da Base de Conhecimento.
6. `business/06-intelligence-roadmap.md` — roadmap para transformar o MVP operacional em plataforma de inteligência técnica.

## Como usar

Use estes documentos como base para:

- criar tarefas no backlog;
- orientar sessões do Codex;
- revisar decisões de produto;
- validar UX;
- alinhar Rafael/Leo sobre visão do negócio;
- manter o projeto longe de uma gerenciadora de tarefas genérica.

A regra central da plataforma é:

> Projetos geram conhecimento. Conhecimento melhora novos projetos.
